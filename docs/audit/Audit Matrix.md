## Disposition

The implementation and locked within-cohort AUROC evidence support the registered narrow empirical question. The evidence does not support presenting the project as a journal-ready methodological contribution. The threshold results rule out describing the configured calibration target as an achieved future-test operating point; the C104 scale mechanism remains exploratory. No algorithmic novelty or independent physical validation is established. Do not reopen confirmatory endpoints to improve the operating threshold; any follow-up requires an independent physical cohort and a prospective estimand and validation plan.
